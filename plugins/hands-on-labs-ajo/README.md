# Hands On Labs - AJO

A dummy Claude Desktop/Cowork plugin for testing marketplace cards and
installation. Its permanent identifier is `hands-on-labs-ajo`, and it
contains exactly one [placeholder skill](skills/hands-on-labs-ajo/SKILL.md).

## Use

Install **Hands On Labs - AJO** from the `techval-coworker-mktplc` marketplace.
Then explicitly ask: "Run the hands-on-labs-ajo placeholder skill."

The skill only acknowledges that it is a placeholder and stops. It does not
implement an Adobe Journey Optimizer lab, call tools, access services, read or
write files, or create or publish artifacts. No connectors, credentials,
hooks, or configuration are included or required.

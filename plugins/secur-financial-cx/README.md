# Secur Financial CX

A dummy Claude Desktop/Cowork plugin for testing marketplace cards and
installation. Its permanent identifier is `secur-financial-cx`, and it
contains exactly one [placeholder skill](skills/secur-financial-cx/SKILL.md).

## Use

Install **Secur Financial CX** from the `techval-coworker-mktplc` marketplace.
Then explicitly ask: "Run the secur-financial-cx placeholder skill."

The skill only acknowledges that it is a placeholder and stops. It does not
implement a customer-experience workflow, call tools, access services, read or
write files, or create or publish artifacts. No connectors, credentials,
hooks, or configuration are included or required.
